# Khulasah Islam · خلاصة إسلام

คลังสรุปแปลหนังสืออิสลามจากภาษาอาหรับ เป็นภาษาไทยและภาษามลายูอักษรยาวี อ่านออนไลน์และดาวน์โหลด PDF ได้ฟรี

## โครงสร้าง

```
books/            หนังสือ 1 เล่ม = 1 ไฟล์ .md (มีทั้งภาษาไทยและยาวีในไฟล์เดียว)
books/_template.md  แม่แบบสำหรับเพิ่มหนังสือใหม่ (ไฟล์ที่ขึ้นต้นด้วย _ จะไม่ถูกนำขึ้นเว็บ)
categories.json   รายชื่อหมวดหมู่ (ไทย / ยาวี / อาหรับ)
pdf/              (ไม่บังคับ) วางไฟล์ PDF ที่จัดหน้าเองไว้ที่นี่ ชื่อ <slug>-th.pdf หรือ <slug>-ms.pdf
src/template.html หน้าตาเว็บไซต์
build.mjs         สคริปต์สร้างเว็บ → โฟลเดอร์ dist/
```

## เพิ่มหนังสือใหม่

1. คัดลอก `books/_template.md` เป็นไฟล์ใหม่ เช่น `books/matan-taqrib.md`
2. แก้ข้อมูลด้านบน (ชื่ออาหรับ ชื่อไทย ชื่อยาวี ผู้แต่ง หมวด) ค่า `category` ต้องตรงกับ `id` ใน `categories.json`
3. เขียนสรุปภาษาไทยใต้บรรทัด `=== th ===` และสรุปยาวีใต้บรรทัด `=== ms ===`
   - `## หัวข้อ` จะกลายเป็นหัวข้อและขึ้นในสารบัญ
   - `- ข้อความ` เป็นรายการ, `> ข้อความ` เป็นกล่องอ้างอิง, `**ตัวหนา**`
4. ตั้ง `sample: false` เมื่อเป็นเนื้อหาจริงที่ตรวจทานแล้ว (ถ้าเป็น `true` จะมีป้าย "ตัวอย่าง")
5. Push ขึ้น GitHub แล้วเว็บจะอัปเดตเองภายในไม่กี่นาที พร้อมสร้าง PDF ให้อัตโนมัติ

## สร้างเว็บในเครื่อง

```
npm install
npx playwright install chromium
npm run build:pdf     # หรือ npm run build ถ้าไม่ต้องการ PDF
```
แล้วเปิด `dist/index.html`

## ขึ้นเว็บด้วย GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings → Pages → Source เลือก **GitHub Actions**
3. ทุกครั้งที่ push เข้า `main` เว็บจะ build และเผยแพร่ใหม่โดยอัตโนมัติ
